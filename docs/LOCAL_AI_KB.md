# 本地 AI 知识库

这份知识库不是外部大模型，也不是联网 API。

它是当前项目用于“本地低阶 AI”判断的一层结构化经验库，主要服务 3 类工作：

- 题型 / 科目推断
- 置信度校准
- 真实版式异常修复

## 数据来源

当前知识库主要根据这两份真实试卷沉淀：

- `模拟卷十一.pdf`

- 言语理解里的 `逻辑填空 / 片段阅读 / 语句表达`
- 判断推理里的 `定义判断 / 类比推理 / 图形推理 / 逻辑判断`
- 资料分析里的 `表格型 / 图形型 / 综合型 / 文字型`

当前已经接入的公开来源示例包括：

- 粉笔的地方省考考情分析与题型整理
- 华图的判断推理、言语理解公开题型解读
- 中公网校的省考题型题量和命题规律分析
- 华图公开真题 PDF 中的整题结构样例

从这两份卷子里，当前已经整理出的稳定经验包括：

- 公务员考试常见六大模块顺序
- 单科整卷与无标题整卷的分段特征
- 资料分析材料的标题、正文、表格、图表模式
- 数量关系 / 判断推理里常见的图片题、图形题、纯数字选项
- 图片选项可能早于 `A/B/C/D` 标签出现的极端版式
- 整卷全资料分析、按年份分段的资料分析历年题版式
- 资料分析首题可能只有一个很短的设问句，但图表被误挂在首题题干图片区
- 政治理论与常识判断都可能使用“下列说法/表述正确”问法，区分关键不在单个词，而在：
  - 是否有总书记讲话、中央文件、政策理论锚点
  - 选项是政策判断还是纯知识判断
- 常识判断不能只按“科技/历史/法律”撞词判断，还要结合：
  - 是否是法条情景题
  - 是否是典故/诗词/地貌/颜色这类知识问答
  - 选项是在做事实判断还是案例匹配
- 言语理解不能只看长题干，还要结合：
  - 是不是概括型选项
  - 是不是逻辑填空的短词对比
  - 数字排序项到底是语句表达还是数量关系
  - `据此 / 与原文相符 / 可以得知` 这类阅读判断问法，哪怕表面出现“下列说法”，本质也常常还是言语阅读
  - 题干里出现 `如果 / 那么` 不代表一定是判断推理，填空题和长阅读里也会自然出现逻辑连接词
- 判断推理不能只看“如果/那么”，还要结合：
  - 短词冒号类比
  - 分组分类选项
  - 约束条件题
  - 集合关系题
  - 人物/位置/颜色/形状这类“关系约束题干”，不能被 `下列说法` 这种通用问法带偏到常识判断
- 数量关系不能只看“有数字”，还要结合：
  - 是否是 `多少 / 约为 / 至少 / 至多 / 平均` 这类数量问法
  - 纯数字选项是不是在做计算，而不是组合项或排序项
- 无标题或低置信度题目，不能只看单题，还要结合相邻题块做二次平滑，避免一整段里只有一题被孤立误判
- 子题型驱动的本地修复规则：
  - `定义判断`：定义段与提问段分行
  - `片段阅读`：长文段与尾部设问分行
  - `语句表达`：句子序号与排序问法分行
  - `逻辑填空`：短词选项优先一行布局
  - `类比推理 / 图形推理`：优先使用更适合的选项布局
  - `图形推理`：如果 4 张图片被错挂在题干而 A-D 为空，会自动按顺序重挂到选项
  - `资料分析`：首题里误挂的材料说明，会尝试移回材料区
  - `资料分析`：首题题干里误挂的图表，会尝试整体移回材料区

## 当前使用方式

### 1. 科目推断

本地推断不再只看零散关键词，还会参考：

- 题干结构
- 选项结构
- 材料/图表特征
- 邻近题块的一致性
- 样卷中已经验证过的高频模式

### 2. 置信度显示

界面展示的“更像什么科目”“置信度多少”会经过本地校准，不再直接把内部原始分差当百分比展示。

### 3. 版式异常修复

真实样卷里已经验证过的异常版式，会直接进入规则层。例如：

- 图片选项先出现，字母标签后出现
- 单科整卷没有标准大标题
- 资料分析只有通用“材料”标题
- 定义判断把“定义正文”和“下列/以下哪项”挤在同一行
- 语句表达把 `①②③④` 句序和“重新排列”提示挤成一段
- 资料分析把图表挂在首题短设问下面，而不是挂在材料区
- 定义判断更像“定义正文 + 案例型选项”，而不是单纯出现“属于/不属于”
- 常识判断更像“知识判断型选项”，往往是整句事实表述而不是案例匹配

## 后续扩展建议

后面每遇到一份真实卷子，不要只补代码规则，最好同步补这两样：

- 在 `data/local_ai_knowledge.json` 里追加该卷的题型范围、显著版式、稳定特征
- 在 `docs/WORKLOG.md` 里记录这份卷子触发了什么问题、最后怎么修的

如果要继续扩库，优先补“官方说明 + 已验证真卷”，不要直接抄整套题库文本：

- 官方说明适合补模块和子题型边界
- 真实真卷适合补版式异常、图片题、跨页题、无标题整卷等工程问题

这样本地 AI 会越用越像“项目自己的经验系统”，而不是越来越难维护的一堆临时 if/else。
