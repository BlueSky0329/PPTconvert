# 公考题型知识总表

这份文档是给本项目的本地 AI 和后续维护看的，不是培训讲义。

目标只有两个：

- 把互联网公开、官方的大纲信息整理成统一题型结构
- 让后续扩库时知道应该往哪里补，不再散落在零碎规则里

## 当前题型总框架

基于已经接入的官方考试说明，当前项目按六大模块组织：

1. 政治理论
2. 常识判断
3. 言语理解与表达
4. 数量关系
5. 判断推理
6. 资料分析

## 子题型映射

### 政治理论

- 党的创新理论
- 党史党章时政

常见特征：

- 题干直接引用党的报告、重要讲话、政策表述
- 高频出现 `习近平`、`中国式现代化`、`高质量发展`、`全面从严治党`
- 选项多为理论判断，不依赖图表和复杂计算

### 常识判断

- 法律常识
- 科技人文地理

常见特征：

- 高频出现 `下列关于`、`下列说法`
- 内容落在法律、科技、历史、文化、地理等知识判断
- 和 `政治理论` 的主要边界在于：
  - 政治理论更偏党的理论与国家方针政策
  - 常识判断更偏知识性辨析

### 言语理解与表达

- 逻辑填空
- 片段阅读
- 语句表达

常见特征：

- 逻辑填空：`填入画横线部分最恰当的是`
- 片段阅读：`这段文字`、`作者意在`
- 语句表达：`重新排列`、`语序`、`衔接最恰当`

### 数量关系

- 工程行程利润
- 排列组合概率
- 几何与数列

常见特征：

- 数字密集
- 题干强调速度、路程、利润、成本、折扣、概率等量化关系
- 选项常为纯数字、分数、百分比，或带图的几何题

### 判断推理

- 定义判断
- 逻辑判断
- 类比推理
- 图形推理

常见特征：

- 定义判断：先定义，再给案例，问 `符合/不符合定义`
- 逻辑判断：`如果...那么...`、`最能削弱`、`最能支持`
- 类比推理：词项关系映射
- 图形推理：问号图、图形序列、图形矩阵

### 资料分析

- 表格型资料分析
- 图形型资料分析
- 综合型资料分析
- 文字型资料分析

常见特征：

- 多题共用一段材料
- 材料包含文字、数字、图表、表格
- 高频出现 `根据以下资料`、`增长率`、`同比`、`比重`

## 对本项目的直接意义

这些题型不是只用于“显示名字”，而是会直接参与：

- 科目推断
- 题型子类推断
- AI 置信度校准
- 待确认题排序
- 后续切题、串题、图片归属修复

例如：

- 识别到 `定义判断` 结构时，`判断推理` 权重会上升，`常识判断` 权重下降
- 识别到 `语句表达 / 重新排列` 时，会更偏向 `言语理解`
- 识别到 `排列组合概率` 和纯数字选项时，会更偏向 `数量关系`
- 识别到 `表格型资料分析` 时，会优先保留材料区域和表格图
- 识别到 `综合型资料分析` 时，会更强调“图、表、文字”混合材料的共同归属
- 识别到 `类比推理` 时，会更偏向短对称选项布局
- 识别到 `图形推理` 时，会优先使用图形友好的网格布局
- 识别到 `图形推理` 且 4 张图被错挂在题干上时，会尝试自动重挂到 A-D 选项
- 识别到 `定义判断 / 片段阅读 / 语句表达` 时，会优先整理题干内部的分段和换行
- 识别到 `逻辑填空` 时，会更偏向短词选项布局，而不是长陈述布局
- 识别到 `资料分析` 首题里夹着材料说明时，会尝试把说明移回材料正文
- 识别到 `资料分析` 首题只是短设问、但图表挂在题干图片区时，会尝试把图表移回材料区
- 识别 `定义判断 / 常识判断 / 逻辑判断 / 片段阅读` 时，会同时参考选项形态，而不是只看题干关键词

## 后续扩库优先级

后续继续扩库时，优先顺序建议是：

1. 官方考试大纲
2. 官方样题或例题
3. 已人工核对过的真实试卷
4. 最后才是网上零散整理题

原因很直接：

- 官方资料最适合补模块定义和子题型边界
- 真实试卷最适合补版式异常和工程问题
- 零散整理题最容易带入错误格式和错误答案，不适合直接喂给本地规则
